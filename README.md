# Connected Animes — アニメのつながりを描く

1本のアニメを起点に、近い作品の地図を描くビューアです。Connected Papers のアニメ版。

## つくり

- **依存ゼロの静的サイト**（`index.html` 1ファイル）。ビルド不要、APIキー不要、サーバー不要
- データは **AniList GraphQL API** をブラウザから直接叩く（CORS 対応済み）
- 類似度は **タグ（ランク重み付き）＋ジャンルの余弦類似度**を土台に、役職別のスタッフ共有と制作会社の一致を加点
- **視聴共起は使っていない**ので、海外ユーザーの嗜好バイアスが入らない。放送直後の新作もその日から描ける
- 同一シリーズ（続編・前作・サイドストーリー・総集編・再編集版・別バージョン）は類似度を独占するため地図から外す。AniList の relations は直接の繋がりしか返さないので、**関係を最大3ホップまで推移的に辿って**シリーズ全体を集める（GraphQL のエイリアスで10件を1リクエストに束ねるため、追加は数リクエスト程度）
- **スピンオフ・共通キャラは除外しない**。別作品であり推薦として価値があるため、地図に残したうえで詳細に「関連するが別作品」として併記する

## 動かす

```bash
# ローカル
python3 -m http.server 5173     # → http://localhost:5173

# Vercel
npm i -g vercel
vercel                          # プレビュー
vercel --prod                   # 本番
```

フレームワークは「Other」、ビルドコマンドなし、出力ディレクトリはルート。
GitHub リポジトリを Vercel に繋いでも、設定なしでそのまま公開されます。

## 主なパラメータ（`index.html` 冒頭）

| 定数 | 既定 | 意味 |
|---|---|---|
| `NODE_LIMIT` | 38 | 起点を除く表示作品数 |
| `EDGE_PER_NODE` | 4 | 1作品あたりの最大接続数。増やすと毛玉になる |
| `EDGE_MIN` | 0.24 | 線を引く最小類似度 |
| `TAG_MIN_RANK` | 40 | これ未満のランクのタグは無視 |
| `FRANCHISE` | SEQUEL / PREQUEL / SIDE_STORY / PARENT / SUMMARY / COMPACT / ALTERNATIVE / CONTAINS | 同一シリーズとみなす関係。ここから外すと地図に載る |
| `FRANCHISE_HOPS` | 3 | 何ホップ先まで同一シリーズとして辿るか |
| `FRANCHISE_MAX` | 70 | 1シリーズから辿る上限 |
| `GENRE_W` | 0.5 | ジャンルの重み。上げるとジャンル一致だけで繋がりやすくなる |
| `COS_LO` / `COS_HI` | 0.12 / 0.67 | 生の余弦をこの範囲で 0〜100% に引き伸ばす |
| `STAFF_CAP` | 0.34 | スタッフ加点の上限 |
| `STUDIO_W` | [0.02, 0.10] | 制作会社の加点幅。作風の一貫性で自動可変 |
| `RADIAL_FORCE` | 0.135 | 同心円へ引き寄せる力の強さ（内半径・外半径幅は `STYLES` 側） |
| `ROLE_W` | 監督0.20 / 原作0.16 / 構成・キャラデザ0.10 / 脚本0.06 / 音楽0.04 | 役職別の重み |

### 表示スタイル（右上の左端ボタンで切替）

| | 円の半径 | 重なり | 合成 | ラベル |
|---|---|---|---|---|
| `overlap`（既定） | 9〜78px | 許容（乗算で濃くなる） | multiply | 円からはみ出す・12文字まで |
| `separate` | 15〜51px | なし（必ず離す） | 通常 | 円の内側に収める |

切替は `STYLES` オブジェクトの1箇所で完結する。半径・衝突判定・リンク距離・同心円の半径・不透明度・ラベルの詰め方をまとめて持つ。

### 配置（2モード。右上の中央ボタンで切替）

- **同心円配置（既定）**：起点との類似度を目標半径に写し、動径方向の力で引き寄せる。**中心からの距離がそのまま類似度**になる。角度方向は自由なので、似た作品どうしのクラスタは残る。点線の輪は類似度の目盛りで、頂点に % を表示
- **クラスタ配置**：動径方向の力を切った、Connected Papers に近い純粋な力学配置。位置は相対的なクラスタのみを表す

jsdom 上での実測（類似度順位と距離順位のスピアマン相関、-1 が理想）:

| 配置 | 相関 |
|---|---|
| 同心円 | **-0.83** |
| クラスタ | -0.12 |

Connected Papers も後者の型で、公式の説明は「似た論文がクラスタとして集まる」であり、起点からの距離が類似度を表すとは述べていない。

### スコアの設計方針

- タグ余弦は実際には 0.15〜0.65 程度しか使われないため、`stretch()` で 0〜1 に引き伸ばしてから加点と合成する。これをしないと加点が相対的に効きすぎる
- ジャンル（Comedy 等）は判別力が低いのに数が少なく norm を占有するため、タグより軽い 0.5 にしている
- 役職判定は完全一致。`Animation Director` `Episode Director` `Sound Director` を監督として拾わない
- 制作会社の加点は固定値ではなく、**その会社の作品群がタグ空間でどれだけ固まっているか**（`coherence()`）で 0.02〜0.10 に可変。作風の明確な会社では効き、受注中心の会社ではほぼ無効になる。値はコンソールに出力される

## 次に足すなら

- **結果のキャッシュ**：`/api/graph` を Vercel Functions で挟み、KV に置く。表示が一瞬になり AniList への負荷も減る
- **日本側の嗜好シグナル**：Annict の GraphQL API から視聴データを取り、ノードの大きさを「日本での人気」に差し替える
- **海外版**：類似度計算を MyAnimeList の視聴共起に差し替える。UI はそのまま使える
